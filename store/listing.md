## 名称

Easy Copilot - AI 对话导航

## 简短说明（≤132 字符）

自动索引 AI 对话里的每一次提问，右侧时间线一键跳转，长对话不用再往上翻。

## 详细说明

```
长对话聊到一半，想回头改第一个问题？

Easy Copilot 会在页面右侧生成一条提问时间线：每一次你发出的提问都会被自动索引，
点一下就能跳回去，鼠标悬停还能看到完整问题。

■ 主要功能
· 自动索引：监听页面变化，新提问即时进入列表，无需刷新
· 一键跳转：平滑滚动到目标提问，并短暂高亮定位
· 悬停预览：列表自动省略过长问题，悬停查看全文
· 明暗主题：跟随宿主页面自动切换，不打断视觉
· 多平台：ChatGPT、DeepSeek、Claude、Gemini、Kimi、通义千问、豆包、腾讯元宝
· 自定义规则：任意站点都能自己填域名 + CSS 选择器，支持导入导出
· 本地优先：配置只写入 chrome.storage.local，不采集、不上传任何对话内容

■ 适合谁
经常和 AI 讨论长文档、写代码、做方案，需要在多个提问之间来回对照的人。

■ 说明
本扩展完全开源，源码与问题反馈：
https://github.com/ylfeng250/easy-copilot
```

## 权限说明（审核填写）

| 权限 | 用途 |
|---|---|
| `host_permissions: https://*/*` | 在各 AI 对话站点注入右侧导航与提问索引，这是扩展的核心功能 |
| `storage` | 保存用户自定义的站点规则（域名 + 选择器）到本地 |
| `activeTab` | 读取当前标签页域名，判断是否已有适配规则，并支持在面板中测试选择器 |
| `scripting` | 在面板里「测试选择器」时统计当前页面的匹配数量 |

不读取、不传输对话内容；无远程代码；无网络请求。
