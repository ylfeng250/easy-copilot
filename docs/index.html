Features

把「翻聊天记录」这件事交给它

索引、定位、预览都在页面内完成，不打断你正在进行的对话。

自动索引

监听页面变化，新提问一出现就进入列表，不用手动刷新。

一键跳转

点击任意一条，平滑滚动到目标提问，并用高亮环短暂标出位置。

悬停预览

列表里的长问题自动省略，鼠标悬停就能看到完整内容。

明暗主题

跟随页面背景明暗切换配色，和宿主界面保持一致。

多平台支持

主流 AI 平台开箱可用；遇到改版也能自己填 CSS 选择器。

本地优先

配置只写入 chrome.storage.local，不采集、不上传对话内容。

Get started

两分钟装好

推荐直接从 Chrome 应用商店安装；想改代码，也可以从源码构建。

Easy Copilot Chrome 应用商店 · 免费 · 一键安装，后续自动更新 添加到 Chrome

或者从源码安装

1

获取代码

克隆仓库，或下载 Release 里的压缩包。

git clone https://github.com/ylfeng250/easy-copilot.git
2

构建产物

安装依赖并打包，产物输出到 build/chrome-mv3-prod。

npm install
npm run build
3

加载扩展

打开 chrome://extensions，开启「开发者模式」→「加载已解压的扩展程序」，选择构建目录即可。
